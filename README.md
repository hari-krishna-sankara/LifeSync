# 🌱 LifeSync – Personal Productivity & Habit Tracker

**Plan Better. Stay Consistent. Grow Every Day.**

LifeSync is a personal productivity and habit-tracking application built using Python and Streamlit. It helps users organize their daily activities, manage tasks, set goals, build positive habits, and monitor their productivity in one place.

With features like smart reminders, a focus timer, weekly reviews, gamification, and productivity analytics, LifeSync makes personal growth easier and more organized.

---

## ✨ Features

### 🔐 User Authentication

- User registration and login
- Individual user profiles
- Profile settings

### 🎯 Goal Management

- Create and manage personal goals
- Track goal progress
- Monitor goal deadlines

### 📝 Task Management

- Add, update, and complete tasks
- Set task priorities and due dates
- Track pending and completed tasks

### 📅 Habit Tracking

- Create and manage daily habits
- Track daily habit completion
- Monitor habit streaks
- View habit progress

### ⏱️ Focus Timer

- Pomodoro-style focus timer
- 25-minute focus sessions
- 5-minute short breaks
- 15-minute long breaks
- Start, pause, resume, and reset timer

### 🔔 Smart Reminders

- Overdue task reminders
- Upcoming task notifications
- Goal deadline reminders
- Daily habit reminders

### 📊 Productivity Analytics

- Visualize productivity progress
- Track completed tasks and goals
- Monitor habit performance
- View productivity statistics

### 📆 Unified Calendar

- View tasks, goals, and activities
- Keep track of important dates
- Organize daily schedules

### 🏆 Gamification

- Earn experience points (XP)
- Track achievements
- Unlock badges
- Stay motivated through progress tracking

### 📈 Weekly Review

- Review weekly productivity
- Track completed activities
- Analyze habit consistency
- Monitor weekly progress

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/LifeSync.git
```

### 2. Navigate to the project directory

```bash
cd LifeSync
```

### 3. Create a virtual environment (Recommended)

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows:**

```bash
venv\Scripts\activate
```

**Mac/Linux:**

```bash
source venv/bin/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.
